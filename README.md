# DREAM HOUSE — Fayoum Real Estate

تم دمج بيانات ملف Excel داخل المشروع مع الحفاظ على النصوص الأصلية للسعر والمساحة والتفاصيل.

## ما تم إضافته
- 210 سجل من ملف Excel.
- 130 سجل من Sheet1 و80 سجل من Sheet2.
- تصنيف تلقائي إلى:
  - الأراضي: 119 سجل.
  - العمارات والمباني: 91 سجل.
- تبويب مستقل داخل قسم العقارات للأراضي والعمارات/المباني.
- الاحتفاظ بالسعر والمساحة كما وردا في Excel، حتى القيم النصية مثل: شراكة، 60,000/م، قيراط، إلخ.
- الاحتفاظ بكل التفاصيل والملاحظات داخل وصف العقار.
- حفظ رقم الصف واسم الشيت ومصدر البيانات لكل سجل.
- البيانات المضافة تُدمج تلقائيًا حتى لو كانت هناك بيانات سابقة في LocalStorage، بدون تكرار السجلات المستوردة.
- ملف `excel-import.sql` جاهز لإدخال نفس بيانات Excel إلى Supabase بعد تحديث الجداول.

## التشغيل
1. فك ضغط المشروع.
2. افتح `index.html` أو شغله على استضافة/سيرفر ثابت.
3. تسجيل الدخول الحالي:
   - Username: `admin`
   - Password: `112203`
4. افتح **العقارات** وستجد تبويبين واضحين: **العمارات والمباني** و**الأراضي**.

## Supabase
- `supabase.sql` يحتوي على أعمدة إضافية لحفظ السعر والمساحة كنص، والتصنيف ومصدر Excel.
- `excel-import.sql` يحتوي على 210 عملية إدخال للبيانات المستوردة.
- شغّل `supabase.sql` أولًا، ثم `excel-import.sql` إذا أردت تخزين نسخة Excel في قاعدة Supabase.

> ملاحظة: نسخة الواجهة الحالية تحفظ البيانات محليًا في المتصفح. تشغيلها على عدة هواتف بنفس البيانات يحتاج ربط الواجهة فعليًا بـ Supabase (Auth + CRUD)، وهو منفصل عن عملية استيراد Excel نفسها.
